## ✨ Visão geral

O aplicativo oferece acesso móvel aos principais módulos do FIXA para solicitantes, técnicos e demais perfis envolvidos no atendimento de manutenção.

## 🚀 Funcionalidades

- Cadastro, autenticação e login com Google
- Recuperação de senha e verificação de e-mail
- Consulta e atualização de perfil
- Criação e acompanhamento de solicitações
- Gestão de ocorrências, ordens de serviço e tarefas
- Gestão de equipamentos, marcas, modelos e categorias
- Consulta e criação de eventos
- Notificações, upload e visualização de imagens
- Indicadores e gráficos operacionais
- Navegação entre módulos e tratamento offline

## 🧰 Tecnologias

| Área | Tecnologias |
| --- | --- |
| **Plataforma** | Android nativo |
| **Interface** | Java e layouts XML |
| **Design** | Material Components e ConstraintLayout |
| **Identidade** | Firebase Authentication e Google Sign-In |
| **APIs** | Retrofit, Gson e OkHttp |
| **Mídia** | Cloudinary e Glide |
| **Gráficos** | MPAndroidChart |
| **Build** | Gradle |
